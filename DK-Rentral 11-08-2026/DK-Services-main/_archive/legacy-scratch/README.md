# Legacy scratch scripts

Standalone experiments predating the `CRM-System` application — plain
`sqlite3`/pandas/reportlab snippets against a throwaway `dk_service.db`
and a nonexistent `employees.xlsx`. Not imported by, or referenced from,
any code in `CRM-System`. `package-lock.json` here has no matching
`package.json` — orphaned from an npm install run at the repo root.

Archived rather than deleted in case any of it is still wanted for
reference.
