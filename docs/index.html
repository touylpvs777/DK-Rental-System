DK CRM — Architecture Overview
Forklift fleet management, rental operations and CRM platform

DK CRM is a full-stack business platform built for DK Service Co. to manage their forklift fleet, rental contracts, customer relationships, maintenance operations and financial billing. The system is built with FastAPI + Python 3.12 on the backend, React 18 + TypeScript on the frontend, and PostgreSQL 16 as the primary data store, deployed via Docker Compose.
